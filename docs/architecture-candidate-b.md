# Candidate B

A typed session state machine owns Clarifying, ReadyToResearch, Researching, Comparing, Recommending, Selected, and Recovering stages. Session events produce new state and typed effects. An effect runner invokes adapters. A bounded manager agent may propose tool calls, but ordinary TypeScript owns constraints, ranking, evidence validation, and state transitions.

Facts and offers carry source references, observation time, currency, region, product/variant identity, and freshness. Budget changes preserve unrelated preferences and rerun discovery. Dissatisfaction produces a preference patch or one targeted follow-up. The UI shows a short recommendation and comparison with expandable evidence.

## Tradeoffs

State transitions make multi-turn and failure invariants visible. A separate event/effect framework adds lifecycle code before the first milestone needs asynchronous background orchestration. The first implementation can preserve explicit result states without a manager-agent runtime.
