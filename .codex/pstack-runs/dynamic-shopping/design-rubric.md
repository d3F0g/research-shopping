# Design rubric

Score each0..2. Compare every whole candidate before selecting.
1. Dynamic product value: open product/criteria intent, useful evidence-backed comparison and conditional recommendation, no fixed category registry or generic count-only answer.
2. Honest semantic boundary: reviewable source/identity/variant/price/criterion support, literal quotes distinguished from synthesis, unknown hard compliance never confident eligibility; no seller-as-manufacturer or fabricated offers.
3. Simplicity and deletion: removes the failed grammar and duplicate ownership, one normal operation and coherent domain shape, no manager/parallel fallback/hidden string DSL.
4. Preserved boundaries: actual SDK body abort, quotas/unknown cost stops/privacy/no fixtures, exact historical envelope/evidence versioning, chat-first official UI.
5. Fast falsifiability: tiny endpoint-risk proof then targeted real captures and four genuine journeys; explicit limits, no huge offline-test loop or acceptance by counts.
