# Battery uncertainty design rubric

Score each criterion0..2. Require at leasttwo independent candidate sketches before synthesis.
1. Truthful output: requested, unestablished battery is explicit perproduct; retained full owned battery quotes stay observed/unverified, not measured or current.
2. One semantic owner: existing private source context and fact recognizer decide ownership/completeness/attribution; no parallel client parser or raw-native inference.
3. Packing correctness: uncertainty follows actually retained public evidence, including omission, ambiguity, capacity/cut/foreign/negative controls.
4. Small API: existing public v2/history unchanged; minimal required private structure and deletion before additions.
5. Verification: exact captured Edifier unknown/ATH qualified pair and independent adversarial retained/omitted/packing controls, no paid calls or weakened old expectations.
