# Design selection rubric

Score each candidate0–5 per criterion after both finish.

1. A minimal actual chat composition replaces the dashboard.
2. Typed history preserves snapshots and gives current actions one owner.
3. Contextual preferences avoid repeated questions and preserve unsupported constraints.
4. Cancellation, exact handoff and Exa boundaries survive retained history.
5. Desktop/mobile typography, density, theme and composer behavior meet the visual brief.
6. Existing official components and backend contracts remain easy to maintain.

Root reads both designs before selecting. A cross-model judge sees the same criteria. Record base, grafts, rejected approaches and unresolved risks. The user, not automated scores, approves the final rendered design direction.
