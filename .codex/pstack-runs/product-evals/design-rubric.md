# Private architecture rubric

Score each design from 0 to 2 on the following criteria.

1. Executes the real normal application handshake without oracle repairs.
2. Blocks paid/external research and shared-ledger mutation independently of environment defaults.
3. Separates provenance, execution coverage and product verdicts with honest denominators.
4. Keeps mutable app contracts inside one adapter and graders independent.
5. Supports blind, attributable, reporting-only semantic evaluation and comparable versioned results.
6. Delivers a small rerunnable system with browser evidence and failure reproduction.

Hold this rubric out of candidate design prompts. It is not passed to the application.
