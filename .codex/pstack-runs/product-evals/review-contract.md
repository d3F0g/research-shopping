# Independent review contract

Goal. Prove the evaluation system measures actual Fieldnote behavior without silently improving observations or consuming Exa credits.

The application baseline is bb51c38748b35d838b44109d72ab4dc9a9847d8c. Reviewers must record exact reviewed base, head, diff scope, commands and verdict. Product behavior is out of evaluation ownership. A product defect stays in the measured report and GitHub tracker.

QA must rerun normal-composition evaluation, inspect per-case traces and category denominators, deliberately regress critical assertions, compare identical and changed expectation versions, and drive browser journeys on desktop and mobile. Failures require preserved traces and screenshots. Unsupported and blocked outcomes never become passes.

Security must challenge external-network denial, absence of live environment loading, in-memory quota isolation, expectation leakage into provider queries, unsafe URL handling, hostile source instructions, untrusted reports and semantic outputs, CI secrets and permissions, and all paths exposed by the CLI. No real credential or ledger access is needed.

Interrogation requires a command and observed failure for each finding. No hypothetical findings or style-only blockers. Reviewers do not edit application or evaluation source. Reproduction scratch files may live only under this worktree's ignored artifact directory.

Semantic scoring is independent of the product author, uses opaque labels and records uncertainty. Agent-reviewed anchors remain pending human review. Uncalibrated scores are reporting-only and never satisfy deterministic gates. A local judge demonstration does not establish human-calibrated product usefulness.

No merge while PR 38 remains unmerged or the latest application implementation has not been integrated and independently verified. This integration block is explicit user scope, separate from CI success.
