# Independent v5 input-quality review

Reviewed 19 November 2026. Turn numbers in this report are one-based; the JSON uses zero-based `turnIndex`.

**Verdict: suitable with substantial disclosed limitations for conditional technical behavior under independently authored synthetic interpretations. Unsuitable as evidence of improved conversational intelligence, natural-language tool restraint, or complete product usefulness.** The tape is usefully transparent about its provenance and many missing operations. ## Hard/flexible semantics and static contract compatibility

The author generally preserves public meaning rather than changing strengths to accommodate the lexical guard. Good examples include hard `Braille output is essential` (FN-PE-003 T1), hard `It has to run on 100 V` (FN-PE-005 T2), and flexible `I'd rather avoid expensive consumables` (FN-MR-004 T2). Explicitly optional portability, quietness, color, warmth, and folding preferences remain flexible. Explicit thresholds, compatibility, exclusions, and necessities are generally hard.

A direct text comparison against the visible `hardCue` pattern found 32 hard actions lacking a recognized cue, plus one flexible action containing a recognized cue: FN-MR-004 T2's “rather avoid.” This is static incompatibility, not an execution result. Earlier validation, local bypasses, or pending state could affect the actual path. Most of these semantic classifications are reasonable; rejection cannot automatically be attributed to poor proposal quality. Conversely, accepting them after a guard change does not demonstrate that the application inferred their strength from raw language—the tape supplied it.

The tape also preserves several important negative distinctions: FN-CD-003 does not turn the rejected 45 W recommendation into a requested lower output; FN-EH-003 does not treat a quoted $35 as a new SGD budget; FN-BC-005 does not replace GBP 100 with a viewed GBP 89 price; FN-CD-005 does not remove the 30 W requirement when the brand restriction is released. These are good authored inputs, with the same upstream-interpretation attribution limit.

## Integration advice that preserves frozen grading

1. Retain the original tape and its hash. If the carryability correction is adopted before results are inspected, publish a distinct input version and record the public-only rationale; do not silently overwrite v1. Keep all grading rules frozen.
2. Call the main lane “conditional application behavior with synthetic intent proposals.” Report supplied interpretation, binding, acceptance/rejection, actual state transition, dispatch, and user-facing completion separately. No manufactured preference snapshots or recovery after failed actions.
3. Keep technical gains but narrow their claims. An acknowledgement-to-no-dispatch result can show implementation of a supplied no-research decision. It cannot show recognition of a held-evidence question or successful completion of that question. A supplied feedback action can show feedback handling, not dissatisfaction recognition. Supplied complete budgets can show validation/preservation, not model memory.
4. Preserve and annotate contract-limited and ambiguous cases instead of excluding failures, weakening expectations, or repairing inputs against application behavior. If the request never reaches research because of unsupported currency or invalid prior actions, disclose that later comparison/cancellation coverage was not established.
5. Let an adapter resolve only the three unique symbolic IDs from actual accepted prior criteria. An absent/ambiguous target is an observable boundary outcome. Selection of the intended target is already authored and must not be credited as application reasoning.
6. Track whether each proposal was consumed or bypassed by a genuine local control/typed-answer path. A passing bypass provides evidence about that path; it provides none about the unused synthetic interpretation.

No claim here assesses final application outputs, hidden grading fairness, live model quality, paid usage restraint, or research usefulness. Those remain outside this review's permitted evidence.
