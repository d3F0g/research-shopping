## Limits and ownership

All engineering used synthetic labeled fixtures, local SDK transports and owned temporary processes/databases. No private capture, environment file, key, ledger, grant, existing database, billable request, production deployment or account setting was accessed. Every owned process launched by completed verifiers was cleaned up. Root's private replay and independent QA/security verdicts are separate evidence. Normal merge gates remain unsatisfied until root accepts the exact final candidate.

The source-row fallback is deliberately bounded to a complete source of at most 4000 UTF-16 units and one scalar money line. Larger, cut, multi-amount or unsupported rows retain raw source without an invented scalar. Monetary-only classification recognizes the shared financial grammar, not all natural-language semantic entailment. Ordinary unfamiliar product descriptions continue to rely on separately labeled provider assessment.

## Principles that changed decisions

- Attack the Premise removed the failed assumption that lexical peer differences prove a different physical product.
- Model the Domain separated a literal catalog observation from an exact-variant attributed price and represented monetary lexical classes explicitly.
- Type System Discipline made V4 observation fields and fixed V2/V3/V4 storage readers separate contracts with independent refinements.
- Fix Root Causes moved money-only recognition into shared monetary grammar and removed destructive replacement-order dependence.
- Minimize Reader Load removed peer heuristics, reused parsed offsets and kept uncertainty concise inside existing disclosures.
- Prove It Works required red behavioral cases, actual Hono/SDK browser journeys, direct screenshot inspection and owned PostgreSQL restart/isolation proof.
